# vivenu

> vivenu is an enterprise-grade, API-first event ticketing platform for live entertainment — sports, music, festivals, and performing arts. It provides white-label ticketing, a REST API with total access to every platform resource (events, transactions, dynamic pricing, inventory), real-time webhooks, prebuilt drop-in checkout and seatmap components, and a unified payments API across global gateways. Used by 1,000+ organizers worldwide.

## API
- [vivenu API (OpenAPI 3.0.3)](https://vivenu.com/api/openapi.json): 450 paths, 504 schemas. Production base https://vivenu.com/api, staging https://vivenu.dev/api. Bearer API-key auth (Authorization header). Core resources: events, tickets, transactions, checkouts, customers, purchase intents, webhooks.
